# 주제 탐색 이력과 미선정 이유

> **2026-11-10 기준, 출품 주제 미확정.** 이 문서는 지금까지 기록에 남은 주제와 변형안을 팀이 한곳에서 비교하도록 모은 이력이다. 아래 안은 현재 제출안이나 개발 지시가 아니다. 사용자 피드백과 검증 결과가 바뀌면 상태를 다시 적는다.

## 읽는 법

- **사용자 탈락**: 사용자가 직접 해당 방향을 내리거나 다른 안을 찾으라고 했다. **추천 철회**: 조사·실험 뒤 우리가 주력 추천을 거뒀다. **보류**: 핵심 가치나 구현이 확인되지 않아 선정하지 않았다. **초기 제외**: 짧은 공개 조사에서 선행 기능·데이터 문제가 보여 깊은 검증으로 진행하지 않았다.
- 표의 이유는 **당시 판단**이다. 유사 앱의 존재만으로 새 안이 불가능하다는 뜻은 아니다. 남는 사용자 문제, 차량 고유 이점, Pleos 실행 경로를 증명하지 못했기 때문에 이번 1차 주제로 선택하지 않았다.
- 기록에 있던 100점 내부 점수와 순위는 2026-10-25 폐기했다. 이를 공식 평가나 합격 가능성으로 재사용하지 않는다. [판단 기록](DECISIONS.md)과 [공식 심사 기준](https://appdevchallenge.auto-hmg.io/guide/judging-awards)을 구분한다.
- 중복되는 변형은 같은 줄에 묶고, 나중에 구체화한 안은 별도 줄에 표시했다. 초기 조사 자료와 팀원 보고서는 후보의 출처이며 사용자 수요·SDK 작동의 증거가 아니다. 개인별 원본 보고서와 개인정보는 저장소에 올리지 않고, 검토 결과만 [독립 재검증](INDEPENDENT_REVIEW_2026-11-09.md)에 요약했다.

## 4. 운전 행동·카메라·개인화 방향

| 주제 | 상태 | 이번 1차 주제로 선정하지 않은 이유 |
