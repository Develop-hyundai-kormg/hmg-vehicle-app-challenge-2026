# 공모전 규칙과 팀 접수 확인표

확인 기준: **2026-11-08 KST**. 아래 요약보다 공식 공지·양식의 최신 문구가 우선합니다.

## 참가와 평가

- 주제는 차량 안에서 새로운 고객 경험을 제공하는 앱이다. [공모전 개요](https://appdevchallenge.auto-hmg.io/guide/overview)
- 개인 또는 **최대 5인 팀**으로 참가한다. 참가 대상은 대학(원)생·일반인·스타트업이며, 시상 부문은 대학생/일반이다. 우리 팀은 **4인 구성**으로 준비한다. 대학생과 대학 졸업 후 일반인이 함께하며, 추가 팀원은 초대 예정이라 학적·역할이 미확인이다. 공개 규정에 혼합팀의 부문 결정 방식이 없어 **4인 구성을 확정한 뒤 운영사무국의 서면 답변이 필요**하다. 답을 받기 전 임의로 부문을 확정하지 않는다. [참가 규정](https://appdevchallenge.auto-hmg.io/guide/rules) · [FAQ](https://appdevchallenge.auto-hmg.io/faq) · [문의 안내](https://appdevchallenge.auto-hmg.io/guide/help)
- 1차 필수 평가는 **차량특화성**, **창의성**, **Pleos SDK/API 활용성**, **사업성**이다. 배점은 비공개다. 사업성에는 타깃, 사용자 확보, 예상 MAU, 재사용률, 확대 가능성이 포함된다. 자체 점수표나 합격 확률을 공식 배점처럼 제시하지 않는다. [심사·시상](https://appdevchallenge.auto-hmg.io/guide/judging-awards)
- 순수 창작물이어야 한다. 표절이나 기수상작, 허위 기재는 제외·취소 사유다. 각 팀원의 과거 공개/제출 이력과 외부 자료의 사용권을 확인한다. [출품 유의사항](https://appdevchallenge.auto-hmg.io/notice/c0a1a000-2026-4923-8000-000000000006)

## 1차 접수: 2026-11-15 23:59 KST

공식 [접수양식 DOCX](https://appdevchallenge.auto-hmg.io/downloads/contest-application-consent.docx)가 **기획서이자 필수 제출물**이다. 공식 [제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission)에 따라 이메일로 접수한다.

양식의 작품 소개 부분은 다음 6개 질문을 중심으로 쓴다.

1. 앱 한 줄 소개
2. 기획 배경: 누구의 어떤 불편이고 왜 해결해야 하는가
3. 주요 기능과 차량 특화 요소: 차 안에서 무엇이 달라지는가
4. 주요 사용 시나리오: 주행 전·중·후의 정확한 흐름
5. 개발 계획: Pleos Connect 앱 범위, SDK/API, 권한, 검증 계획
6. 기대효과와 발전 가능성: 타깃, MAU·재사용률의 가정, 확장

기획서만으로도 지원할 수 있다. **목업·프로토타입·화면 녹화 영상**은 선택 제출이고 가산점 대상이다. GitHub 저장소를 제출하려면 **소스 코드와 실행 가능한 release APK를 함께** 두고 `apk/` 경로를 적는다. APK만 따로 보내지 않는다. 비공개 저장소도 허용되지만 공식 안내의 심사용 GitHub 계정 접근을 마감 전에 확인해야 한다. 가산점의 크기는 공개되지 않았다. 숏폼 챌린지는 별도 시상이며 본상 가산점이 아니다. [제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission)

대표자를 포함한 **팀원 전원**이 개인정보 동의 여부·서명·날짜를 작성하고, 대표자가 팀원 전원을 이메일 CC에 넣는다. 참가 기본정보와 서명은 공식 양식에만 기재하고, 작품 소개·이 저장소·공유 시안에는 개인 연락처를 넣지 않는다. 작성된 동의서는 저장소에 커밋하지 않는다. 마감 전 수정 제출은 공식 안내의 제목·전체 첨부·CC 요건을 다시 따른다. [제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission)
