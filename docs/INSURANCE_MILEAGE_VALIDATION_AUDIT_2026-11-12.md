# 〈할인 경계〉 검증 감사와 선정 정정

기준일: **2026-11-12 KST**. 사용자가 “검증 했어?”라고 지적했을 당시의 답은 **핵심 검증을 하지 못했다**였다. 그 뒤 같은 날 [Linux Pleos AVD 경로거리 실행 시험](NAVI_DESTINATION_DISTANCE_RUNTIME_PROBE_2026-11-12.md)으로 기술 항목 하나를 추가 확인했다. **보험 특약 운전자의 실제 효용과 재사용성은 여전히 미검증**이므로 〈할인 경계〉의 1차 제출 추천 보류는 유지한다.

| 질문 | 확인 결과 | 증거 수준 |
|---|---|---|
| 실제 보험 거리 구간과 할인 차이가 존재하는가 | [DB손해보험 공식 표](https://m.directdb.co.kr/comm/bnf/evt/atarcDstTtyView.do?pageDvn=trvDstc)에 특정 개인승용 조건에서 1만km 이하 13.2%, 다음 1만500km 이하 8.3%가 표시된다. | 공식 문서 확인 |
| 거리 초과가 실제 불편으로 드러나는가 | [금융감독원 소비자경보 사례](https://m.samsungfire.com/download/consumer/ca_d12.pdf)에는 마일리지 **선할인** 계약자가 약정 거리를 초과해 만기 후 추가보험료를 요구받고 민원을 제기한 사례가 있다. 초과 불편의 직접 사례지만, 출발 전 경로 비교 기능의 수요를 증명하지는 않는다. | 공개 민원 사례 확인 · 제품 수요 미확인 |
| 예시 4만9천원 계산이 맞는가 | 가상 할인 계산 기준 보험료 100만원에 4.9%포인트를 곱하면 4만9천원이다. 9,850km + 160km = 10,010km이다. 실제 보험증권의 할인 적용 대상 보험료나 환급액은 확인하지 않았다. | 산술 확인, 가상 사례 |
| Pleos에서 차량 누적거리를 읽을 수 있는가 | 과거 Windows Pleos AVD에서 Vehicle SDK READ capability와 정적 현재값 **0.0**을 읽었다. 실제 주행거리 변화·실차·제품 앱은 검증하지 않았다. [기술 기록](TECHNICAL_VALIDATION.md) | 제한적 실행 확인 |
| 순정 내비의 현재 경로 km를 제3자 앱이 받는가 | Linux Pleos Connect v2.1.0 AVD에 공식 NaviHelper 샘플을 설치했다. 좌표 요청 경로 12km/20분을 순정 내비에 띄우고 `getDestinationInfo()` → `onDestinationInfo(remainDistance=12000, remainTime=1200)`을 받았다. 콜백 목적지 좌표도 요청과 일치했다. 원본 POI 샘플은 요청 좌표와 응답 목적지가 약 9.53km 달랐으므로 목적지 일치 검사가 필요하다. [재현·화면](NAVI_DESTINATION_DISTANCE_RUNTIME_PROBE_2026-11-12.md) | **AVD 실행 확인**. 제품 앱·실차는 미확인 |
| 기존 제품보다 운전자 결정을 개선하는가 | 보험사 앱·블루링크는 누적거리/정산을 다루고 [Sonnet Shift](https://www.sonnet.ca/shift-faqs)는 예측 할인율을, [차셈](https://chasem.co.kr/insurance/mileage/)은 남은 구간 거리를 제공한다. 현재 경로와의 결합이 과제 시간·오류·실제 선택을 개선하는지는 이용자 비교가 없다. 공개 검색에서도 해당 선택을 실제로 바꾼 운전자 사례를 확보하지 못했다. | 선행 기능 확인, 사용자 가치 미확인 |
| 재사용·사업성이 있는가 | 가까운 할인 경계와 만기 시점이 겹칠 때 가치가 큰데, 그 이용자 비중·설치 의사·월 재방문율을 측정하지 않았다. 설치 시 계약값 입력 부담도 검증하지 않았다. | 미확인 |

**정정:** 공식 1차는 기획서만으로 접수할 수 있다. [공식 심사](https://appdevchallenge.auto-hmg.io/guide/judging-awards)의 차량 특화성·창의성·SDK 활용성·사업성 중 **경로거리 SDK 실행 가능성은 AVD에서 확인**했으나, 실제 계약값 결합·사용자 선택 개선·사업성은 아직 약하다. 11월 14일까지 실제 특약 운전자의 기존 방법 비교가 확인되지 않으면 ‘고객이 선택을 바꾼다’고 쓰지 않는다. 기획서 문안은 [후보 문서](FIRST_ROUND_TOPIC_INSURANCE_MILEAGE_2026-11-12.md)에만 보존한다.
