# 제품 목표와 후보 판단

기준일: **2026-11-09**. 이 문서는 원래 사용자 요구와 과거 후보 평가를 보존한다. **현재 팀 검토용 1차 작업 주제는 〈다음 운전자〉**이며 최종 출품 확정은 아니다. [선정 이유·탈락 조건](FIRST_ROUND_DIRECTION_2026-11-09.md). 아래 후보표의 이전 상태 판단은 당시 기록이다.

## 사용자가 요청한 경험

1. 설치·동의 후 차량 시동에 맞춰 앱이 자동으로 대기한다. 매번 앱을 열거나 내비 목적지를 입력하지 않는다.
2. 내비 화면을 열지 않고 목적지도 설정하지 않은 평소 주행에서 접근하는 단속카메라를 **약 250m 전**에 알린다. 반복 경로 학습은 이 경고의 필수조건이 아니다.
3. 순정 내비게이션이 작동하는 동안에는 앱 자체 경고를 억제해 중복 안내를 피한다. 어느 상태 신호로 순정 안내를 정확히 알 수 있는지는 미확인이다.
4. 운행 후 첫 화면은 점수·등급 대신 **짧은 관찰 체크리스트**다. 운전자는 관찰 내용을 확인하거나 자신의 상황과 다르다고 정정하고, 필요한 항목만 자세히 본다.
5. 반복 경로와 운전 습관 복습은 장기 확장 가능성이다. 출발 전 10초 브리핑은 과거 AI 제안이며 확정된 요구가 아니다.

위 1~3과 4는 서로 연결될 수 있으나, **주차 후 체크리스트를 카메라 기능의 실현이라고 표현하지 않는다.** 수동으로 앱을 여는 시연도 자동 대기 경험을 증명하지 않는다.

## 후보별 현재 판단

| 후보 | 목표 결과 | 상태 | 결정 전 핵심 질문 |
|---|---|---|---|
| A. 무목적지 카메라 경고와 순정 내비 중복 억제 | 내비를 쓰지 않는 운전에도 필요한 경고를 한 번만 듣는다 | 원래 목표, **1차 주력 보류**. 핵심 자동 동작·정책 미검증 | 대상 차의 순정 경고와 무엇이 다른가? 무경로 카메라 이벤트·위치·자동 실행·오디오가 허용/동작하는가? |
| B. 주차 후 관찰 체크리스트와 맥락 정정 | 관찰된 운전 장면을 과실 판정 없이 이해한다 | **1차 주력 보류**. 기존 대안과 사용자 재사용 근거 부족 | 기존 운전 분석보다 운전자가 매주 다시 쓸 이유가 있는가? 사건의 관찰·저장·주차 후 제시가 가능한가? |
| C. 환자 하차→보호자 주차→픽업 | 환자와 운전자의 분리 동선을 한 방문 흐름으로 잇는다 | **주력 추천 해제**. 경유지 미리보기는 실행했지만 사업성·차량 고유 이점 미검증 | 반복 방문자의 실제 과제에서 일반 지도보다 행동이 나아지는가? 병원별 장소 데이터 유지가 가능한가? |
| D. 낯선 차 조작 리허설 | 처음 타는 차의 조작을 빨리 익힌다 | **우선 후보에서 제외** | 기존 디지털 설명서/계기판보다 낫고, 일회성 이후 재사용되는가? |
| E. 어린이집 경유 누락 조기 알림 | 등원 경유를 놓친 상태를 이동 중 알린다 | **안전 효과 주장 보류** | 자동 감시와 아동 존재 확인, 오탐·미탐이 안전 주장의 기준을 충족하는가? |
| F. 누적거리 기반 업무용 운행기록 | 업무 운행 거리와 용도를 정확히 기록한다 | **검증 트랙**. Pleos 거리 읽기는 실행, 기존 제품과 차별성 미확인 | 기존 운행기록 사용자의 어떤 반복 비용을 계기판 값 직접 읽기가 줄이는가? 구간은 어떻게 나누는가? |
| G. 공용차 인수인계 | 다음 운전자가 미완료 조치를 출발 전에 안다 | **조건부 탐색**. 연료 핵심 신호가 현재 에뮬레이터에서 미지원 | 기존 예약·반납 앱보다 나은가? 지원 차량에서 핵심 신호와 사용자 간 공유가 되는가? |

과거 탐색안인 버스차로 조기 진입 경고와 시각장애 동승자 경로 공유는 국내 선행 서비스·데이터/음성 한계로 현재 추천에서 내렸다. 새로운 근거가 나오면 다시 검토할 수 있다.

**누적거리 기반 업무용 운행기록**은 Pleos 누적거리 조회가 됐지만 Pleos Fleet·카택스의 기존 자동 운행기록과 겹친다. **공용차 연료 인수인계**는 현재 Pleos 에뮬레이터에서 Fuel Percent 조회가 미지원이다. EV SOC는 읽혔으나 충전 시작 여부는 증명하지 못했다. [시험 조건과 결과](INDEPENDENT_REVIEW_2026-11-09.md), [최신 후보 판단](DIRECTION_REASSESSMENT_2026-11-09.md)을 함께 본다.

## 차별성의 현재 반례

- [현대 블루링크 안전 운전 습관](https://www.hyundai.com/kr/ko/digital-customer-support/app/myhyundai/bluelink/bluelink-vehicle-care/safe-driving-habits)과 [Kia App 드라이빙 인사이트](https://www.kia.com/kr/customer-service/kia-members/kia-app/mycar)는 급가감속 등 차량/주행 데이터에 기반한 분석을 이미 제공한다.
- [TMAP 운전점수](https://www.tmapmobility.com/service/drive/ubi)는 운전 이력과 주행 패턴을 분석하고, [네이버 지도 운전분석](https://www.navercorp.com/media/pressReleasesDetail?seq=31882)도 맞춤형 분석을 제공한다. `점수 없는 체크리스트`만으로 고객 가치가 입증되지 않는다.
- [Samsara Driver App](https://kb.samsara.com/hc/en-us/articles/37898532707341-Review-Shared-Events-and-Your-Driver-Score)은 운행 이벤트 검토와 사유 의견을 제공한다. 따라서 `이벤트를 보여주고 운전자가 맥락을 보탠다`는 패턴 자체가 새로운 발명이라는 주장은 약하다. 이는 국내 개인 차량에서의 사용 가치가 없다는 결론은 아니다.
- [현대 순정 내비 카메라 경고 설정](https://ownersmanual.hyundai.com/ivi/ccNC/AVNT/KOR/Korean/Settings_navigation.html)이 있다. 목적지/내비 화면 없이도 경고가 나오는지 **대상 Pleos 차종에서 직접 확인**해야 A의 남는 가치를 판단할 수 있다.
- 국내 공개 운전자 경험담은 차로 변경 압박·급감속 맥락·야간/우천 시야 같은 문제를 알려 주지만 대표 표본이나 앱 재사용 의사를 증명하지 않는다. 실제 운전자 확인이 필요하다.

## 선택에 사용할 질문

후보마다 `누구의 반복 불편인가 → 기존 해결책이 남긴 빈틈은 무엇인가 → 차량 정보가 어떤 결정을 바꾸는가 → 1차에 검증된 장면을 보여줄 수 있는가 → 2차에 동작 앱이 되는가`를 답한다. 어느 후보도 한 질문의 근거가 없으면 **미확인**으로 표시한다. 공식 심사 배점이 공개되지 않았으므로 과거 내부 100점표와 75점 문턱은 사용하지 않는다.
